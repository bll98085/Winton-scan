# 文中進項憑證檔案式匯入

每批額外產生 `進項憑證明細檔_YYYYMMDD_<用戶代號>.xls`，預設放在來源 PDF／合併 CSV 的資料夾。範本為 本技能資料夾內的 assets/進項憑證明細檔.xls（可用 -Template 覆寫），以原生 Excel 97–2003 格式另存，保留範本第一列所有 33 欄（A:AG）的名稱、順序、格式及註解。資料從第二列開始；範本第二列範例與第三列說明不進入結果。依下表填 A:O 與 W，其中 G、I 留白；P:V、X:AG 也留白。原範本不被修改。

## 欄位

| 欄 | 範本原始欄名 | 規則 |
|---|---|---|
| A | 送件年月 | 每批由使用者自行輸入，民國年三碼＋月份兩碼，例如 `11510`。不得自動帶入當月；本批已明確指定時直接使用。 |
| B | 用戶代號 | 本批開始時選定的代號。 |
| C | 所屬年(起) | CSV「計費期間」起日的民國年三碼，例如 `115`。 |
| D | 所屬月(起) | CSV「計費期間」起日的月份兩碼，例如 `03`。 |
| E | 所屬月(迄) | CSV「計費期間」迄日的月份兩碼，例如 `05`；不使用發票月份或載具年期碼。 |
| F | 憑證類別 | 固定 `1`。 |
| G | 第冊數 | 留白，不編冊。 |
| H | 扣抵否 | 使用者稱「折抵否」；保留範本原欄名。原單稅額大於零填 `Y`；零稅額或稅額缺少時留白，缺少稅額須列待確認。 |
| I | 序號(進項憑證) | 留白，不編號。 |
| J | 類別(進項憑證) | 固定 `2`。 |
| K | 憑證金額 | 依原發票未稅金額；優先用核對後的 `certificate_amount`，或由同張發票含稅金額減原單稅額取得。水費排除代收費用。 |
| L | 稅別 | 固定 `5`，不得填舊銷項格式的 `05`。 |
| M | 稅額 | 原發票／帳單上的營業稅。電信 CSV 原本留空，需另從各電話號碼所屬的本月一般稅率／營業稅明細讀取。讀不到就留白，不假設為零。 |
| N | 日期 | CSV「收款日期」，民國年三碼＋月份兩碼＋日期兩碼，例如 `1150601`。有收款章時取章內日期；沒有收款章日期時取帳單上方繳費日期。 |
| O | 賣方統編 | 供應商／開票公司的 8 碼統編，保留前導零；遠傳為 `97179430`。 |
| W | 發票號碼&繳納證號碼 | 預設 `-InvoiceMode carrier`，取 CSV「發票號碼」欄的本期載具流水號 10 碼，例如 `BBJU300154`，與 CSV 一致。帳面雲端發票號碼如 `AN13377352` 保留於 CSV 備註；只有使用者明確要求才改用 `-InvoiceMode printed`。載具號碼缺少時留白並列待確認，不用帳面或前期號碼補空。 |

A、B、C、D、E、F、H、J、L、N、O、W 寫成文字（符合範本代碼欄格式）；K、M 寫成數值，缺值保留空白。不要把金額的千分位逗號當成文字寫入。第一列的 `所屬年(起)`、`扣抵否`、`序號(進項憑證)`、`類別(進項憑證)`、`發票號碼&繳納證號碼` 均保留原文，不依使用者簡稱改標題。

憑證金額以此進項範本的範例（金額 20,000、稅額 1,000）按未稅金額處理；若使用者指定含稅金額，應依其明確指示調整，不可把舊銷項二聯式含稅規則套回此範本。

所屬年／月起迄依帳單計費區間填寫，例如 `115/03/14-115/05/15` 或 `115/03/14至115/05/15` 填 C=`115`、D=`03`、E=`05`。支援完整民國或西元起迄日；日期缺少、無效或迄日早於起日時，C:E 留白並列待確認，不改用發票日期、繳費年月或載具年期碼。範本只有「所屬年(起)」，沒有「所屬年(迄)」；跨年區間仍填起年與起迄月並列待確認，不新增或改名欄位。

N「日期」依 CSV「收款日期」填寫。優先取收款章內的日期；沒有可辨識的收款章日期時，改取帳單上方「繳費日期」。不得改用抄表日期、計費期間、下次扣款日期、列印日期或載具年期碼。兩者都無法確認時留白並列待確認。

## 補充資料介面

保持合併 CSV 的 14 欄與順序不變；新增的「收款日期」直接作為匯入 N「日期」來源。其他匯入專用資料記錄在本批暫存資料夾的 `details.json`，以已去除連字號的電號／水號／電話號碼作為索引：

```json
{
  "4P516664203": {
    "invoice_date": "115/06/01",
    "printed_invoice": "AN13377352",
    "certificate_amount": "4573",
    "gross_amount": "4802",
    "tax_amount": "229",
    "tax_status": "reviewed",
    "evidence": "範例格式；實際執行須以本批原單核對，不能沿用這些範例值"
  }
}
```

`invoice_date` 與 `invoice_month` 僅保留舊批次相容性，不再決定 N「日期」；N 一律來自 CSV「收款日期」。`certificate_amount` 是核對後的未稅憑證金額；`gross_amount` 是同張發票的含稅金額；`tax_amount`、`printed_invoice` 是從原單核對後的補充值，`printed_invoice` 只在明確選用 `printed` 模式時寫入 W；`evidence` 記錄來源／頁碼／欄位。電費通常以 CSV 應繳金額減營業稅取得未稅金額；水費含稅小計可從 CSV 備註「水費小計…元」取得再減稅，不用包含代收費用的總額；電信須核對發票含稅金額並補原單稅額。含稅金額或稅額不足以核對時，不自行假設零稅額、套用稅率或取總額當未稅金額。

計費期間、開立日期或所選模式的本期號碼無法確定時，各自留白並列待確認；缺少開立日期不影響已核對的所屬年／月起迄。匯出工具把缺少／無法驗證的欄位列為 ⚠️，在最終回覆列出，不額外塞進範本未要求的欄位。

`tax_status` 可為 `source`（原單 OCR 讀值）、`derived`（推算／修正或檢核異常）、`missing`（未讀到）、`reviewed`（已核對原單）。`derived`／`missing` 或 CSV 註記稅額推算／檢核異常時，匯出工具會將稅額與扣抵否留白；改成 `reviewed` 必須同時提供明確 `tax_amount` 與非空白 `evidence`。僅移除警示文字不算核對。已核對的值可保留，尚有異常仍須在最終報告說明。

批次工具同步產生 `details.draft.json` 候選值與 `review.json` 統一清單；複核後另存最終 `details.json`。收款日期優先從收款章擷取；沒有章內日期才使用繳費日期；多個候選值不自動選一個。電信 `gross_amount` 須取同張發票含稅金額，缺少時不再以 CSV 繳費總額代替。水費含稅小計直接保留在補充資料，避免依賴備註文字完整性。

## 執行與驗證

雙擊啟動器採兩階段處理：沙箱內完成辨識、複核、CSV 與指定位置的 `details.json`，再以相同批次參數執行下列工具，另加 `-PrepareOnly -ReadyFile '<本批暫存資料夾>\export_ready.json'`。工具檢查資料後產生完成標記，記錄客戶、送件年月、路徑與輸入檔 SHA256，不啟動 Excel。標記只在全部複核完成後建立；若修改 CSV、補充資料、manifest 或來源，先移除本批標記再重新準備。沒有補充資料時仍須將指定的 `details.json` 寫成 `{}`。

外層啟動程式會以目前登入的 Windows 使用者，將相同參數及 `-ReadyFile` 傳給匯出工具（不加 `-PrepareOnly`），核對標記後重新建立匯入資料並產生 XLS。標記缺少、輸入有變動、準備失敗或輸出已存在時停止並保留已完成資料。此流程不在 Codex 沙箱帳號內啟動 Excel，也不更動全域沙箱設定。手動直接匯出則在可使用 Excel 的登入環境執行原有命令。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '<skill-root>\scripts\export_winton_import.ps1' -Csv '<來源資料夾>\帳單_YYYYMMDD.csv' -UserCode H11037 -SubmissionMonth '<使用者輸入的五碼民國年月>' -DetailsJson '<本批暫存資料夾>\details.json' -Manifest '<本批暫存資料夾>\manifest.json' -SourcesJson '<本批暫存資料夾>\sources.json'
```

`-Manifest` 必填：逐一核對來源 PDF 雜湊、全部頁面 OCR、解析與重掃記錄、最終 CSV 每頁筆數。`-SourcesJson` 在啟動器流程使用其固定選取清單。任何漏頁、漏列或來源變更會在 Excel 啟動前停止。CSV 的警示也會合併進匯入報告。

`-SubmissionMonth` 使用本批由使用者輸入的值；省略時 PowerShell 工具會詢問，Python helper 則拒絕缺少此值，不預設當月。`-UserCode` 省略時顯示既有公司選單並詢問。`-Template` 覆寫範本位置；`-Output` 覆寫匯出位置。首次執行確認 Excel 已安裝；不自動安裝套件或替換環境。工具先複製範本到暫存目錄，再以隱藏的獨立 Excel 執行個體唯讀開啟副本，另存 `.xls` 後重新開啟核對第一列、註解、所有輸出值及識別碼的文字型別；發布前確認原範本 SHA256 未變。只關閉工具自己建立的 Excel，不終止使用者既有的 Excel 程序。

已存在的同名匯出檔預設拒絕覆寫；若本次作業已明確授權重新產生同名輸出，可以使用 `-Overwrite`。範本與合併 CSV 始終保留。彙整結果報告本批用戶、送件年月、總筆數，以及仍待補的匯入欄位。
