# Winton-scan 移機使用說明

請複製整個 winton cmd 資料夾，不能只複製 winton-scan.cmd。
本包已附完整 skill、程式、規則參考文件、Excel 範本與套件版本清單。
CMD 會指定本地 skill，無須另外安裝到新電腦的 .codex。
本包尚未包含 Python、Windows OCR、Excel 或 Codex 執行環境。

## 資料夾擺放

可放在任意可寫入的本機資料夾，例如：

    D:\Winton-scan\
      待辨識帳單.pdf
      winton cmd\
        winton-scan.cmd
        check-environment.cmd
        SKILL.md
        requirements.txt
        scripts\
        references\
        agents\
        assets\進項憑證明細檔.xls

雙擊後預設讀取 winton cmd 的上一層直接放置的全部 PDF，不含子資料夾。
CSV 與 XLS 也輸出在該上一層。原本放在 Winton-scan\winton cmd 時行為相同。
範本使用包內 assets\進項憑證明細檔.xls，不再依賴特定 Windows 使用者名稱。
客戶代號與辨識規則沿用原 skill。

## 新電腦首次設定

1. 使用 Windows，安裝 Microsoft Excel 桌面版並確認能正常開啟；網頁版 Excel 無法供程式進行 COM 匯出。
2. 安裝 Python 3.12 64 位元。程式優先使用 %LOCALAPPDATA%\Programs\Python\Python312\python.exe，不存在時使用 PATH 的 python.exe。
3. 在本資料夾開啟 PowerShell，為程式實際使用的 Python 安裝套件：

       $wintonPython = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python312\python.exe'
       if (-not (Test-Path -LiteralPath $wintonPython)) { $wintonPython = (Get-Command python.exe).Source }
       & $wintonPython -m pip install -r .\requirements.txt

   清單記錄來源電腦於 2026-10-13 的版本；套件下載尚未在全新電腦驗證，本包不是離線安裝包。
4. 安裝 Windows 繁體中文（台灣）OCR 語言功能。即使使用 RapidOCR，現有程式仍使用 Windows OCR 判斷頁面方向；zh-Hant-TW 檢查必須通過。
5. 安裝 Codex CLI 並在新電腦登入。先備妥 Node.js/npm，再依 [OpenAI 官方 npm 安裝範例](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex) 執行：

       npm.cmd install -g @openai/codex
       codex.cmd login
       codex.cmd login status

   登入方式見 [官方驗證說明](https://learn.chatgpt.com/docs/auth)。來源電腦 CLI 為 0.162.1；新版本須實際確認相容性。模型沿用 gpt-6-luna，需要新帳號可使用該模型及正常網路／額度；可用 -Model 指定帳號可用模型。先啟動一次 codex.cmd 完成必要的 Windows 環境設定，再關閉回到本程式。本包不含原電腦登入資訊或全域 Codex 設定。
6. 雙擊 check-environment.cmd 查看 Python／套件／OCR／範本／Excel 註冊／Codex 本地登入狀態。它不會安裝套件、送出模型作業或處理正式帳單。
7. 放入要處理的 PDF，雙擊 winton-scan.cmd，依序輸入送件年月與客戶代號。

## 自訂路徑與驗證

在 CMD 中可明確指定 PDF 資料夾或範本：

    winton-scan.cmd -ScanDir "D:\帳單" -Template "D:\範本\進項憑證明細檔.xls"

加上 -SubmissionMonth 11510 -UserCode <有效客戶代號> -DryRun 可顯示選檔與輸出路徑，不啟動 OCR、Codex 或 Excel；須有 PDF 才會完整顯示批次資訊。

環境檢查通過不等於新電腦已完成端到端驗證：模型／沙箱／網路及 Excel 實際匯出仍需新電腦首次執行確認。
快取與未完成複核存於原電腦 %TEMP%，不在此包內；本包用於新批次，不能直接接續另一台電腦的中斷批次。
